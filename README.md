# Angel Hours

Enter a time you saw on a clock (for example `11:11`, `3:33` or `7:48`) and read what the number means and what to do next.

Each reading shows:

- the pattern (triple, quadruple, mirror hour, double hour, sequence or personal number)
- the core message
- three actions to take, plus an affirmation
- guidance for love, career and spirit
- the meaning of each digit and the root number

## Run it

Open `index.html` in a browser. There is no build step and no server.

## Files

- `index.html`: the page
- `styles.css`: the styling
- `app.js`: time parsing, pattern detection and rendering
- `meanings.js`: the interpretation data

Angel numbers are a tradition of symbolic reflection, not prediction.
